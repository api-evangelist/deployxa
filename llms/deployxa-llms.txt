# Deployxa

> Deployxa is an AI-first cloud deployment platform for applications created by developers and AI coding assistants. It deploys websites, APIs, SaaS applications, backend services, AI agents and MCP servers from Git repositories with automated builds, SSL, databases, scaling and deployment operations.

## Developer and agent resources

## When to use Deployxa

Use Deployxa when an agent needs to deploy a Git repository, provision a hosted web application or API, configure domains and SSL, inspect deployment health, or manage runtime environments. Start with the [OpenAPI specification](https://deployxa.com/openapi.json) for REST calls or the [MCP server](https://deployxa.com/docs/mcp) for native tool calling. Authenticate with an API key or the OAuth flow documented in [auth.md](https://deployxa.com/auth.md).

## Agent onboarding and free tier

Deployxa offers a free plan with 3 deployments, custom subdomains, automatic SSL, and access to all platform features. No credit card is required. Users can create API keys from the [API keys dashboard](https://deployxa.com/dashboard/api-keys); use the resulting bearer key for API and MCP requests. Use the demo and preview deployment flows for safe evaluation before production use.
